# Änderungen klein und nachvollziehbar halten

- Ändere nur, was für die angeforderte Aufgabe notwendig ist.
- Bewahre bestehende Konventionen und öffentliches Verhalten, sofern keine Änderung gewünscht ist.
- Prüfe betroffene Tests oder Diagnosen und fasse das Ergebnis knapp zusammen.
